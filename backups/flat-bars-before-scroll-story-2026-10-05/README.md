# Flat Bars page restore point

Saved on 2026-10-05 before replacing the Flat Bars product page with the scroll-driven 3D story.

To restore the previous Flat Bars page, copy the files in this folder back to the same relative paths at the project root, then run `npm run build:source`. The original shared `ProductDetail.jsx`, preview widget, loader, styles, and HTML entry files are included. The current footer and other product pages were not changed for the scroll story.

This folder is a snapshot, not part of the running site.
